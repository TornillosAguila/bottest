🔑 Generador de hash PBKDF2

Genera un registro de usuario para data/users.json. La contraseña nunca se transmite; el hash se calcula en tu navegador.
Parámetros: PBKDF2-HMAC-SHA256 · 100,000 iteraciones · salt 16 bytes aleatorios · clave 256 bits.
Deben coincidir con los del runtime (auth.js) y con users.json._meta.iterations.
